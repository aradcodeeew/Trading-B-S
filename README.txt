# B&S Trade App

Created by Arad.

B&S is a trading companion application designed to help traders organize, analyze, and improve their performance.

Features include:

* Trading journal and trade tracking
* Risk and position size calculations
* Trading notes and personal lessons
* Educational trading content
* Strategy documentation and development
* Performance review and self-analysis tools
* Flexible workspace for every trader to build and record their own system
